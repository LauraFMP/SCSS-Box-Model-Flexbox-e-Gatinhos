# 🐱 MiAU.exe

Uma página web temática de gatos com estética **8-bit/pixel art**, criada para praticar conceitos de **HTML, CSS e Flexbox**.

## ✨ Sobre o projeto

O **MiAU.exe** é uma pequena comunidade felina fictícia, com uma interface inspirada em jogos retrô e cultura pixel art.

A página apresenta:

* 🐾 Galeria de gatinhos
* 🐱 Perfil da semana
* 💡 Curiosidades sobre gatos
* 🧶 Dicas para um gato feliz
* 🎮 Interface com estética 8-bit
* 📱 Estrutura organizada e acessível

## 🛠️ Tecnologias

* HTML5
* CSS3
* Flexbox
* Google Fonts
* Pixel Art / estética retrô

O projeto utiliza as fontes **Press Start 2P** e **VT323** para reforçar a identidade visual 8-bit.

## 📂 Estrutura

```text
📦 MiAU.exe
 ├── index.html
 └── style.css
```

## 🚀 Como executar

1. Clone este repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

Não é necessário instalar dependências.

## 🎯 Objetivo

O projeto foi desenvolvido para praticar **estruturação de páginas HTML, estilização com CSS e organização de layouts utilizando Flexbox**, criando uma interface temática e responsiva.
